# Week 10 推荐系统与 MovieLens

## 目标

把深度学习和推荐系统、特征工程、大数据场景连接起来。

## 练习

- 使用 MovieLens 或小型模拟数据。
- 构造 user、item、context 特征。
- 训练 embedding-based 推荐模型。
- 做离线评估。

## 运行

```bash
python3 labs/week10-recommender-movielens/scripts/train.py
```

知识点文档：`docs/07-推荐系统与大数据场景/01-recommender-embedding.md`

## 验收标准

- 能说明样本 label 如何产生。
- 能解释 user embedding 和 item embedding。
- 能区分召回、排序和评估指标。
