# Week 12 综合项目

## 目标

独立完成一个小型深度学习项目，覆盖数据、训练、评估、保存、推理和复盘。

## 可选题目

- 图像分类。
- 文本分类。
- 推荐排序。
- 离线批量预测。

## 运行

```bash
python3 labs/week12-final-project/scripts/train.py
```

知识点文档：`docs/08-训练工程化/01-final-project-workflow.md`

## 验收标准

- 有清晰的问题定义。
- 有数据说明和处理流程。
- 有训练配置和指标记录。
- 有测试或最小验收脚本。
- 有最终复盘报告。
