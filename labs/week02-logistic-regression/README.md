# Week 02 逻辑回归与二分类

## 目标

理解二分类任务中的 sigmoid、交叉熵和分类阈值。

## 练习

- 构造或加载一个二分类数据集。
- 实现逻辑回归模型。
- 比较 accuracy、precision、recall。
- 调整分类阈值，观察指标变化。

## 运行

```bash
python3 labs/week02-logistic-regression/scripts/train.py
```

知识点文档：`docs/02-机器学习基础/01-logistic-regression-classification.md`

## 验收标准

- 能输出混淆矩阵。
- 能说明 loss 和 accuracy 的区别。
- 能解释阈值变化对 precision 和 recall 的影响。
