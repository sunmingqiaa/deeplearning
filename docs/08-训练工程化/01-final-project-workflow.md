# 综合项目工作流

## 一句话理解

综合项目的目标是把数据、训练、评估、导出和推理串成一个可复查的闭环。

## 核心知识点

- 问题定义：明确输入、输出和评价指标。
- 数据说明：记录来源、字段、标签含义。
- 基线模型：先做一个简单但能跑通的版本。
- 指标记录：保存配置、loss、metric 和样例预测。
- 模型导出：保存推理需要的参数和词表。
- 复盘：记录有效做法、失败尝试和下一步动作。

## 对应实验

```bash
python3 labs/week12-final-project/scripts/train.py
```

实验会完成一个工单优先级文本分类小项目，输出：

```text
labs/week12-final-project/outputs/model.json
labs/week12-final-project/outputs/metrics.json
```

## 验收问题

- 这个项目的输入和输出是什么？
- 指标是否能反映业务目标？
- 模型导出的内容是否足够推理？
- 下一版最应该优化数据、模型还是评估？
