# MLP 多层感知机

## 一句话理解

MLP 通过多层线性变换和非线性激活函数，把简单线性模型扩展成能拟合复杂模式的模型。

## 核心知识点

- 输入层：接收特征向量。
- 隐藏层：学习中间表示。
- 激活函数：引入非线性，例如 ReLU。
- 输出层：分类任务通常接 softmax。
- 反向传播：根据 loss 更新每层参数。

## 重点理解

如果没有激活函数，多层线性层叠加后仍然等价于一层线性层。MLP 的能力来自“线性变换 + 非线性激活”的组合。
