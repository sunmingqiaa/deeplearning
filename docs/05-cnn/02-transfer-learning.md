# 迁移学习

## 一句话理解

迁移学习把已有模型学到的通用特征拿来复用，只针对新任务训练少量参数或做微调。

## 核心知识点

- 预训练模型：在大数据集上提前训练好的模型。
- Backbone：负责提取通用特征的主体网络。
- 分类头：面向当前任务的最后几层。
- 冻结参数：不更新 backbone，只训练分类头。
- 微调：在预训练参数基础上继续训练部分或全部参数。

## 重点理解

小数据集上从零训练容易过拟合。复用预训练特征可以减少数据需求，提高收敛速度。

## 对应实验

```bash
python3 labs/week07-transfer-learning/scripts/transfer_demo.py
```

实验用固定卷积特征模拟 frozen backbone，对比原始像素特征训练分类头。
