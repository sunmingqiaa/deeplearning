# 深度学习常用词汇表

这份文档不是单纯背名词，而是用来建立深度学习的基础语感。每个词尽量回答四件事：它是什么、为什么需要它、常见问题是什么、怎么处理。

## 最常见训练流程词汇

| 词汇 | 解释 | 重点理解 |
| --- | --- | --- |
| 样本 Sample | 一条训练数据。例如一张图片、一句话、一条用户点击记录。 | 深度学习训练本质上是从大量样本中学习输入到输出的规律。 |
| 特征 Feature | 描述样本的信息。例如图片像素、用户年龄、文本 token、商品类目。 | 传统机器学习很依赖人工特征；深度学习能自动学习一部分特征，但输入质量仍然关键。 |
| 标签 Label | 监督学习里的目标答案。例如图片类别、是否点击、评分、房价。 | 标签质量直接决定模型上限，错误标签会误导模型。 |
| 张量 Tensor | 多维数组，是 PyTorch、TensorFlow 中的核心数据结构。 | 标量是 0 维，向量是 1 维，矩阵是 2 维，高维数组统称张量。 |
| Shape | 张量每个维度的大小。 | 例如图像 batch 常见 shape 是 `[batch_size, channels, height, width]`。shape 错误是新手最常见 bug。 |
| Batch | 一次送入模型训练的一组样本。 | 不会通常一条一条训练，也不会每次都把全量数据送进去，而是切成很多 batch。 |
| Batch Size | 一个 batch 里的样本数量。 | batch size 影响显存、训练速度、梯度稳定性和泛化效果。 |
| Mini-Batch | 小批量训练。每次用一小批样本估计梯度并更新参数。 | 实际深度学习训练基本默认就是 mini-batch 训练。 |
| Epoch | 模型完整看完一遍训练集。 | 如果训练集有 10000 条，batch size 是 100，那么 1 个 epoch 有 100 个 step。 |
| Step / Iteration | 一次参数更新。 | 通常一个 batch 对应一个 step。训练日志里的 step 不是 epoch。 |
| Shuffle | 每个 epoch 前打乱训练数据。 | 避免模型按固定顺序看到数据，降低训练偏差。 |
| Dataset | 数据集抽象，负责返回单条样本。 | PyTorch 中通常实现 `__len__` 和 `__getitem__`。 |
| DataLoader | 批量读取 Dataset 的工具。 | 负责 batch、shuffle、多进程加载等。 |

## Batch 详细理解

### Batch 是什么

Batch 是一次训练送入模型的一组样本。假设你有 10000 条训练数据，batch size 设置为 128，那么训练时不是一次处理 10000 条，而是每次处理 128 条左右。

### 为什么需要 Batch

- 单条样本训练：梯度噪声大，训练很抖。
- 全量样本训练：每次更新都要扫完整训练集，计算慢，占内存。
- mini-batch：在效率和稳定性之间折中，所以最常用。

### Batch Size 的影响

| Batch Size | 优点 | 问题 |
| --- | --- | --- |
| 小 batch | 显存占用低，梯度有噪声，有时泛化更好。 | loss 曲线更抖，训练速度可能慢。 |
| 大 batch | 并行效率高，梯度更稳定。 | 占显存，可能泛化变差，通常需要调整学习率。 |

### 常见计算

如果训练集有 `N=10000` 条，`batch_size=128`：

```text
steps_per_epoch = ceil(10000 / 128) = 79
```

训练 `10` 个 epoch，大约会更新参数：

```text
total_steps = 79 * 10 = 790
```

### 常见问题

- 最后一个 batch 可能不足 batch size。
- BatchNorm 对 batch size 比较敏感，batch 太小统计量不稳定。
- batch size 改大后，学习率可能也要调整。
- 做序列任务时，不同长度样本组成 batch 通常需要 padding。

## 数据处理词汇

| 词汇 | 解释 | 重点理解 |
| --- | --- | --- |
| 归一化 Normalization | 把数据缩放到更统一的范围或分布。 | 目的是让不同特征的尺度接近，训练更稳定。 |
| 标准化 Standardization | 常见公式是 `(x - mean) / std`。 | 让数据均值接近 0，标准差接近 1。 |
| Min-Max Scaling | 把数据缩放到 `[0, 1]` 或 `[-1, 1]`。 | 常用于数值特征或图像像素。 |
| 数据增强 Data Augmentation | 对训练样本做随机变换，例如翻转、裁剪、加噪声。 | 增加样本多样性，缓解过拟合。 |
| Padding | 对序列或图像边缘补值。 | 文本 batch 中常用于把不同长度句子补齐。CNN 中用于控制输出尺寸。 |
| Mask | 标记哪些位置有效、哪些位置应该忽略。 | Transformer 里常用 attention mask 忽略 padding 或未来 token。 |
| One-Hot | 把类别变成只有一个位置为 1 的向量。 | 类别很多时 one-hot 很稀疏，所以推荐、NLP 常用 embedding。 |
| Token | 文本被切分后的单位，可以是词、子词或字符。 | 大语言模型常用子词 token。 |
| Vocabulary | 词表，token 到 id 的映射。 | 模型不能直接处理字符串，需要先转成 id。 |
| Embedding | 把离散 id 映射成稠密向量。 | user_id、item_id、word_id 都可以用 embedding。 |
| 数据泄漏 Data Leakage | 训练时用了本不该知道的信息。 | 例如用未来数据预测过去，会让离线指标虚高。 |
| 类别不平衡 Class Imbalance | 某些类别样本远多于其他类别。 | accuracy 可能失真，需要看 precision、recall、AUC 等。 |

## 归一化详细理解

### 为什么要归一化

如果一个特征范围是 `0-1`，另一个特征范围是 `0-100000`，模型训练时大数值特征会主导梯度，导致优化不稳定。归一化可以让不同特征处于接近的尺度。

### 常见做法

| 方法 | 公式 | 适用场景 |
| --- | --- | --- |
| 标准化 | `(x - mean) / std` | 大多数连续数值特征。 |
| Min-Max | `(x - min) / (max - min)` | 需要固定到 `[0, 1]` 的场景。 |
| 图像归一化 | `(pixel / 255 - mean) / std` | 图像模型训练。 |
| BatchNorm | 对 batch 内中间激活做归一化。 | CNN、MLP 中常见。 |
| LayerNorm | 对单个样本的特征维度归一化。 | Transformer 中常见。 |

### 常见坑

- 训练集和测试集不能分别计算归一化参数。应该用训练集的 mean/std 处理验证集和测试集。
- 归一化和正则化不是一回事。归一化处理数据分布；正则化限制模型复杂度。
- 类别 ID 不应该直接当连续数值归一化，通常要用 embedding。

## 模型结构词汇

| 词汇 | 解释 | 重点理解 |
| --- | --- | --- |
| 模型 Model | 从输入到输出的函数，内部有可学习参数。 | 训练就是不断调整模型参数。 |
| 参数 Parameter | 训练过程中会被更新的值。 | 例如权重、偏置、embedding 表。 |
| 超参数 Hyperparameter | 人为设定，不是模型自动学出来的值。 | 例如学习率、batch size、层数、隐藏层维度。 |
| 权重 Weight | 神经网络连接上的可学习系数。 | 决定输入特征对输出的影响。 |
| 偏置 Bias | 线性变换中额外加上的常数项。 | 让模型输出可以平移，不必总经过原点。 |
| 层 Layer | 一个计算模块。 | 例如 Linear、Conv、BatchNorm、Dropout。 |
| 全连接层 Linear / Dense | 每个输入都连接到每个输出。 | 常用于 MLP 和分类头。 |
| MLP | 多层感知机，由全连接层和激活函数组成。 | 适合表格特征、简单分类、基础实验。 |
| Logits | softmax 或 sigmoid 之前的原始输出分数。 | 训练分类模型时，交叉熵通常直接接收 logits 更稳定。 |
| 激活函数 Activation | 给网络引入非线性。 | 没有激活函数，多层线性网络仍等价于一层线性模型。 |
| ReLU | `max(0, x)`。 | 简单高效，是最常见激活函数之一。 |
| Sigmoid | 输出范围是 `(0, 1)`。 | 常用于二分类输出，但隐藏层中可能导致梯度消失。 |
| Tanh | 输出范围是 `(-1, 1)`。 | 比 sigmoid 居中，但也可能饱和。 |
| Softmax | 把多类别 logits 转成概率分布。 | 多分类输出常用。 |
| CNN | 卷积神经网络。 | 适合图像、局部模式明显的数据。 |
| 卷积 Convolution | 用小窗口在输入上滑动提取局部特征。 | 比全连接层更适合图像，因为共享参数并保留空间结构。 |
| 卷积核 Kernel / Filter | 卷积的小矩阵。 | 可以检测边缘、纹理、局部模式。 |
| Channel | 通道。 | RGB 图片有 3 个输入通道。卷积层也会产生多个输出通道。 |
| Stride | 卷积核移动步长。 | 步长越大，输出尺寸越小。 |
| Pooling | 降采样操作，例如 max pooling。 | 压缩空间尺寸，保留显著特征。 |
| RNN | 循环神经网络。 | 处理序列数据，但长序列容易梯度消失或爆炸。 |
| LSTM / GRU | 带门控机制的 RNN 改进结构。 | 用门控缓解长期依赖难学的问题。 |
| Attention | 根据相关性加权聚合信息。 | 让模型知道当前 token 应该关注哪些位置。 |
| Self-Attention | 序列内部 token 之间互相计算 attention。 | Transformer 的核心。 |
| Transformer | 基于 self-attention 的模型结构。 | 现代 NLP、大模型、多模态模型的基础。 |
| 残差连接 Residual Connection | 把输入直接加到后续输出上。 | 让梯度更容易回传，缓解深层网络难训练。 |
| Backbone | 主干网络，负责提取通用特征。 | 迁移学习中经常冻结 backbone。 |
| Head | 任务头。 | 接在 backbone 后，用于分类、回归、检测等具体任务。 |

## 激活函数详细理解

### 为什么需要激活函数

线性层只能做线性变换。如果多个线性层中间没有激活函数，那么它们叠起来仍然等价于一个线性层。激活函数引入非线性后，模型才能拟合复杂关系。

### 常见激活函数对比

| 激活函数 | 优点 | 问题 | 常见用途 |
| --- | --- | --- | --- |
| ReLU | 计算简单，缓解梯度消失。 | 输入长期小于 0 时可能死亡。 | CNN、MLP 隐藏层。 |
| Leaky ReLU | 负数区域也保留很小梯度。 | 多一个斜率超参数。 | 缓解 ReLU 死亡。 |
| Sigmoid | 输出可解释为概率。 | 两端饱和，梯度容易变小。 | 二分类输出层。 |
| Tanh | 输出以 0 为中心。 | 也会饱和。 | 早期 RNN、部分门控结构。 |
| GELU | 平滑，Transformer 常用。 | 计算比 ReLU 复杂。 | Transformer、BERT 类模型。 |

### 常见问题

- Sigmoid/Tanh 在隐藏层里容易引起梯度消失。
- ReLU 可能出现神经元死亡，表现为某些神经元永远输出 0。
- 输出层激活函数要和任务匹配：二分类常用 sigmoid，多分类常用 softmax，回归通常不用限制输出范围。

| 词汇 | 解释 | 重点理解 |
| --- | --- | --- |
| 前向传播 Forward | 输入经过模型得到预测结果。 | 得到 logits、概率或回归值。 |
| 损失函数 Loss Function | 衡量预测和真实标签差距。 | 训练目标是让 loss 下降。 |
| MSE | 均方误差。 | 常用于回归，对大误差惩罚更重。 |
| MAE | 平均绝对误差。 | 对异常值没有 MSE 那么敏感。 |
| BCE | 二元交叉熵。 | 用于二分类或多标签分类。 |
| Cross Entropy | 交叉熵。 | 多分类最常见损失函数。 |
| 反向传播 Backpropagation | 从 loss 开始反向计算梯度。 | 本质是链式法则。 |
| 梯度 Gradient | loss 对参数的变化率。 | 梯度方向告诉我们参数怎么改会影响 loss。 |
| 梯度下降 Gradient Descent | 沿负梯度方向更新参数。 | `param = param - lr * grad`。 |
| 优化器 Optimizer | 根据梯度更新参数的算法。 | SGD、Adam、AdamW 都是优化器。 |

| Momentum | 动量。 | 累积历史梯度方向，减少震荡。 |

| 学习率 Learning Rate | 每次更新参数的步长。 | 太大容易发散，太小收敛慢。 |
| Scheduler | 学习率调度器。 | 训练过程中动态调整学习率。 |

| Autograd | 自动求导。 | 框架记录计算图并自动算梯度。 |

| Checkpoint | 训练保存点。 | 通常包含模型参数、优化器状态、epoch、指标。 |
| Train Mode | 训练模式。 | Dropout、BatchNorm 在训练模式和评估模式行为不同。 |
| Eval Mode | 评估模式。 | 推理前需要切到 eval，否则结果可能不稳定。 |

## 损失函数详细理解

### 损失函数是什么

损失函数把“预测错得有多离谱”变成一个数字。训练过程就是不断调整参数，让这个数字下降。

### 常见损失函数

| 任务 | 常用损失 | 解释 |
| --- | --- | --- |
| 回归 | MSE / MAE | 预测连续值，例如价格、温度、评分。 |
| 二分类 | Binary Cross Entropy | 预测 0/1，例如是否点击、是否异常。 |
| 多分类 | Cross Entropy | 多个类别中选一个，例如图片分类。 |
| 多标签分类 | BCEWithLogits | 一个样本可以同时属于多个标签。 |
| 排序/推荐 | BPR、Pairwise Loss | 关注正样本排序是否高于负样本。 |

### 常见坑

- Loss 下降不代表业务指标一定变好，需要同时看 metric。
- 分类任务中 logits、sigmoid、softmax、cross entropy 的组合要匹配。
- 类别极度不平衡时，普通交叉熵可能偏向多数类，需要 class weight、重采样或 focal loss。

## 优化与稳定性词汇

| 词汇 | 解释 | 重点理解 |
| --- | --- | --- |
| 过拟合 Overfitting | 训练集好，验证集差。 | 模型记住训练集细节，但泛化不好。 |
| 欠拟合 Underfitting | 训练集和验证集都差。 | 模型能力不够、训练不足或特征不足。 |
| 泛化 Generalization | 模型在新数据上的表现能力。 | 真正有价值的是泛化能力，不是训练集分数。 |
| 正则化 Regularization | 限制模型复杂度的方法。 | 用来缓解过拟合。 |
| L1 正则 | 惩罚参数绝对值。 | 可能让部分参数变成 0，有特征选择效果。 |
| L2 正则 / Weight Decay | 惩罚参数平方。 | 抑制权重过大，最常用。 |
| Dropout | 训练时随机关闭部分神经元。 | 减少模型对某些局部路径的依赖。 |
| BatchNorm | 对 batch 的中间激活做归一化。 | 训练更稳定，但依赖 batch 统计。 |
| LayerNorm | 对单个样本的特征维度归一化。 | Transformer 中常用，不依赖 batch size。 |
| 梯度爆炸 Gradient Explosion | 梯度过大，参数更新过猛。 | loss 震荡、发散、NaN。 |
| 梯度消失 Gradient Vanishing | 梯度过小，前面层几乎学不动。 | 深层网络和长序列模型常见。 |
| 梯度裁剪 Gradient Clipping | 限制梯度最大范数或范围。 | 常用于缓解梯度爆炸。 |
| 参数初始化 Initialization | 训练前给参数赋初值。 | 初始化不合理会导致训练慢、梯度爆炸或消失。 |
| Xavier 初始化 | 适合 tanh/sigmoid 一类激活。 | 目标是保持前后层方差稳定。 |
| He 初始化 | 适合 ReLU 一类激活。 | ReLU 网络常用。 |
| Early Stopping | 验证集不再提升时停止训练。 | 防止继续训练导致过拟合。 |
| NaN | Not a Number。 | 常由学习率过大、除以 0、log(0)、梯度爆炸导致。 |

## 梯度消失详细理解

### 梯度消失是什么

梯度消失是指反向传播时，越往前面的层梯度越小，最后小到几乎不能更新参数。表现就是后面的层还能学，前面的层基本不动，模型训练很慢或效果上不去。

### 为什么会发生

反向传播依赖链式法则。多层网络的梯度会连续相乘：

```text
前面层梯度 = 后面梯度 * 第 N 层导数 * 第 N-1 层导数 * ...
```

如果这些导数大多小于 1，连续相乘后会越来越接近 0。

常见原因：

- 网络太深，链式相乘路径太长。
- Sigmoid/Tanh 进入饱和区，导数接近 0。
- RNN 处理长序列时，同一权重反复参与链式相乘。
- 参数初始化不合理，使激活值过大或过小。
- 没有归一化层，前后层分布不断漂移。

### 典型现象

- loss 下降很慢。
- 前面层参数几乎不变。
- 前面层梯度 norm 非常小。
- 深层网络比浅层网络更难训练。
- RNN 很难学到长距离依赖。

### 应对方法

| 方法 | 作用 |
| --- | --- |
| 使用 ReLU / Leaky ReLU / GELU | 减少 sigmoid/tanh 饱和导致的小梯度问题。 |
| 使用合适初始化 | ReLU 常用 He 初始化，tanh 常用 Xavier 初始化。 |
| 使用 BatchNorm / LayerNorm | 稳定中间激活分布，减少梯度异常变小。 |
| 使用残差连接 | 给梯度提供更短路径，ResNet、Transformer 都大量使用。 |
| 使用 LSTM / GRU | 在 RNN 中通过门控机制缓解长期依赖问题。 |
| 降低网络深度或调整结构 | 先让模型能训练，再逐步加深。 |
| 监控梯度 norm | 定位是哪一层开始梯度变小。 |

## 梯度爆炸详细理解

### 梯度爆炸是什么

梯度爆炸是指反向传播时梯度变得非常大，导致参数一次更新过猛，训练不稳定。严重时 loss 会变成 `inf` 或 `NaN`。

### 为什么会发生

同样来自链式法则。如果反向传播路径上的导数或权重范数持续大于 1，连续相乘后梯度会指数级变大。

常见原因：

- 学习率过大。
- 网络太深或序列太长。
- RNN 反复乘同一类权重矩阵。
- 参数初始化过大。
- 输入没有归一化，导致激活值和梯度过大。
- loss 本身数值不稳定，例如对 0 取 log。

### 典型现象

- loss 突然变得非常大。
- loss 变成 `NaN` 或 `inf`。
- 参数值越来越大。
- 梯度 norm 异常大。
- accuracy 随机波动，模型无法收敛。

### 应对方法

| 方法 | 作用 |
| --- | --- |
| 降低学习率 | 最直接的排查方式。 |
| 梯度裁剪 | 把梯度 norm 限制在阈值内，RNN 常用。 |
| 合理初始化 | 避免初始权重过大。 |
| 输入归一化 | 避免输入尺度过大传导到梯度。 |
| 使用 BatchNorm / LayerNorm | 稳定中间层分布。 |
| 检查 loss 计算 | 避免 `log(0)`、除以 0、指数溢出。 |
| 使用更稳定的框架 API | 例如 PyTorch 里用 `CrossEntropyLoss`，不要手写 `softmax + log`。 |

## 评估指标词汇

| 词汇 | 解释 | 重点理解 |
| --- | --- | --- |
| 训练集 Training Set | 用来训练模型的数据。 | 模型直接从它学习参数。 |
| 验证集 Validation Set | 用来调参、选模型。 | 不参与参数训练，但参与模型选择。 |
| 测试集 Test Set | 最终评估泛化能力。 | 不应该频繁看，否则会间接过拟合测试集。 |
| Accuracy | 预测正确比例。 | 类别不平衡时可能误导。 |
| Precision | 预测为正的样本中，有多少是真的正。 | 关注“报出来的准不准”。 |
| Recall | 真实为正的样本中，有多少被找出来。 | 关注“漏掉多少”。 |
| F1 | Precision 和 Recall 的调和平均。 | 适合需要兼顾 precision 和 recall 的场景。 |
| AUC | 衡量二分类排序能力。 | 推荐、广告、风控常用。 |
| RMSE | 均方根误差。 | 回归和评分预测常用。 |
| 混淆矩阵 | 统计 TP、FP、TN、FN。 | 用来分析分类错误类型。 |
| Top-K Accuracy | 真实类别是否在模型前 K 个预测里。 | 多分类、检索、推荐中常见。 |

## 推荐与大数据场景词汇

| 词汇 | 解释 | 重点理解 |
| --- | --- | --- |
| 稀疏特征 Sparse Feature | 大量取值但单条样本只命中少数值。 | user_id、item_id、category_id 都是典型稀疏特征。 |
| 稠密特征 Dense Feature | 连续数值或低维数值特征。 | 年龄、价格、统计指标等。 |
| 召回 Recall Stage | 从海量候选里快速找出一批可能相关的 item。 | 重视速度和覆盖率。 |
| 排序 Ranking Stage | 对召回候选做精排。 | 重视准确率和业务目标。 |
| CTR | 点击率。 | 推荐、广告中常预测用户是否点击。 |
| Negative Sampling | 负采样。 | 从未点击或未交互样本中采样负例，控制训练规模。 |
| 特征穿越 Feature Crossing | 组合多个特征。 | 例如用户城市和商品类目组合。 |
| 离线训练 | 用历史数据批量训练模型。 | 和大数据平台关系密切。 |
| 在线特征 | 推理时实时可拿到的特征。 | 要和离线训练特征保持一致。 |

## 工程实践词汇

| 词汇 | 解释 | 重点理解 |
| --- | --- | --- |
| 推理 Inference | 用训练好的模型做预测。 | 推理阶段不更新参数。 |
| 在线推理 Online Inference | 服务实时接收请求并返回结果。 | 关注延迟、稳定性、吞吐。 |
| 离线预测 Batch Prediction | 批量对大量数据做预测。 | 关注吞吐、任务调度、数据落表。 |
| Pipeline | 从数据处理、训练、评估到推理的流程。 | 工程上要能复现和排错。 |
| 实验记录 Experiment Tracking | 记录配置、指标、代码版本、模型产物。 | 不记录实验，很难复现和比较。 |
| 模型版本 Model Version | 模型产物的版本标识。 | 应该和代码、数据、特征版本对应。 |
| 训练偏移 Training-Serving Skew | 训练和推理使用的特征处理不一致。 | 会导致离线效果好、线上效果差。 |
| 监控 Monitoring | 监控延迟、错误率、输入分布、预测分布、业务指标。 | 模型上线后数据分布可能变化。 |
| 数据漂移 Data Drift | 线上数据分布和训练数据分布不同。 | 需要监控和定期重训。 |

## 高频易混词

| 易混词 | 区别 |
| --- | --- |
| Loss vs Metric | Loss 用于训练优化，Metric 用于评价效果。两者可以不同。 |
| 参数 vs 超参数 | 参数由训练学出来；超参数由人设定。 |
| 归一化 vs 正则化 | 归一化处理数据或激活分布；正则化限制模型复杂度。 |
| Batch vs Epoch vs Step | Batch 是一批样本；Epoch 是完整看完一遍训练集；Step 是一次参数更新。 |
| 验证集 vs 测试集 | 验证集用于调参和选模型；测试集用于最终评估。 |
| Sigmoid vs Softmax | Sigmoid 常用于二分类或多标签；Softmax 常用于单标签多分类。 |
| 过拟合 vs 欠拟合 | 过拟合是训练好验证差；欠拟合是训练和验证都差。 |
| 梯度爆炸 vs 梯度消失 | 梯度爆炸是梯度过大导致发散；梯度消失是梯度过小导致前面层学不动。 |
| BatchNorm vs LayerNorm | BatchNorm 依赖 batch 统计；LayerNorm 对单个样本归一化，更适合 Transformer。 |
