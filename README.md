# 深度学习学习仓库

这个目录用于系统学习深度学习，目标不是只看概念，而是把每个概念落到可运行实验、可验证测试和可复盘文档中。

## 学习原则

- 每个重要概念至少对应一篇笔记。
- 每个阶段至少有一个可运行实验。
- 每个实验必须记录配置、指标、现象和问题。
- 优先使用 PyTorch，后续再扩展到工程化部署和大数据场景。
- 先把训练流程跑扎实，再追复杂模型。

## 目录说明

| 路径 | 用途 |
| --- | --- |
| `00-roadmap.md` | 总学习路线和阶段目标 |
| `docs/` | 概念笔记、专题整理、问题清单 |
| `labs/` | 每周最小实验和练习代码 |
| `src/` | 可复用训练、数据、模型、评估代码 |
| `tests/` | pytest 测试，验证 shape、训练流程和保存加载 |
| `datasets/` | 数据集说明、原始数据、处理后数据和样例 |
| `experiments/` | 每次实验的配置、指标、日志和模型产物 |
| `reports/` | 周复盘和项目总结 |
| `references/` | 链接、论文、外部资料 |
| `logs/` | 运行日志或外部系统日志 |

## 推荐学习节奏

每周固定交付四类内容：

1. 一组概念笔记。
2. 一个可运行实验。
3. 一组基础测试。
4. 一篇周复盘。

## 当前主线

从 `00-roadmap.md` 开始，按周推进。每完成一个实验，在 `experiments/` 下新建日期目录记录配置和结果。

## 直接运行

当前 12 个 lab 都提供了标准库可运行版本，不需要先安装 PyTorch：

```bash
python3 tests/run_smoke_tests.py
```

如果要检查 PyTorch 等可选依赖：

```bash
python3 scripts/check_environment.py
```
